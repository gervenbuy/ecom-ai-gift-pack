剪映自動剪輯 Skill 教學JianYing Auto-Editing Skill Guide

讓 Claude 用一句話，把資料夾裡的素材自動排進剪映時間軸：配樂、字幕、配音、轉場都幫你搭好，你只要打開剪映檢查、微調、匯出。

Let Claude turn one sentence into a ready-to-edit JianYing (剪映) draft: it lays your clips on the timeline with music, captions, voice-over and transitions. You just open JianYing, review, tweak and export.

🧩 luoluoluo22/jianying-editor-skill 💻 Windows 🕒 2026-10-12

整體流程

  • ① 確認剪映
  • ② 裝 Python／Git／FFmpeg
  • ③ 安裝 Skill
  • ④ 驗證讀到草稿
  • ⑤ 一句話生成草稿
  • ⑥ 剪映檢查＋匯出

這個 Skill 負責「自動幫你把時間軸搭好」，最後的預覽、渲染與匯出仍然在剪映裡完成。

前提確認

  1. 電腦要安裝「剪映專業版」（中國國內版電腦版，從 jianying.com 下載）。CapCut 國際版和手機版都不支援。
  2. 剪映裡至少要有一個草稿。沒有的話，先打開剪映建一個空白草稿。
  3. 使用 Claude 桌面版，並開「本機」工作階段（雲端工作階段碰不到你電腦裡的剪映）。

1檢查並補裝 Python、Git、FFmpeg

打開 PowerShell，先檢查：

python --version; git --version

如果有缺，執行下面這行補裝：

winget install Python.Python.3.12 Git.Git Gyan.FFmpeg

裝完一定要把 PowerShell 關掉重開，新的路徑才會生效。

2安裝 Skill（手動、安全版）

⚠️ 不要使用 README 裡的 irm ... | iex 一鍵安裝。它用短網址下載腳本後直接執行，內容不透明。請用下面的手動方式。

git clone https://github.com/luoluoluo22/jianying-editor-skill.git "$env:USERPROFILE\.claude\skills\jianying-editor"
cd "$env:USERPROFILE\.claude\skills\jianying-editor"
git checkout 32c56928ded4f9e2c2b80e099dc7abb793d2c30b
(Get-Content requirements.txt) -replace '==.*','' | Set-Content req-loose.txt
python -m pip install -r req-loose.txt
python -m playwright install chromium

每一行在做什麼

  • git clone：把 Skill 下載到 Claude 的技能資料夾 ~\.claude\skills\jianying-editor，Claude 才找得到它。
  • git checkout 32c5692…：鎖定在 v1.7 這個已檢查過的版本，避免作者之後的更新內容未經檢查就被執行。
  • req-loose.txt：把 requirements 的版本鎖定拿掉，避免較新的 Python（例如 3.14）找不到相容套件。
  • pip install：安裝 Skill 需要的 Python 套件。
  • playwright install chromium：安裝「網頁動效轉影片」錄屏用的瀏覽器。

3驗證有沒有讀到剪映

還在同一個資料夾裡，執行：

python scripts\draft_inspector.py list --limit 5

✅ 有列出剪映的草稿名稱，就是安裝成功。

如果出錯：把完整錯誤訊息貼給 Claude，請它幫你排除。常見原因是剪映裡還沒有任何草稿、裝的是 CapCut 而不是剪映專業版，或補裝完沒重開 PowerShell。

4之後怎麼使用

  1. 在 Claude 桌面版開一個「本機」工作階段（不要用雲端）。
  2. 工作資料夾選放素材的資料夾。
  3. 直接說需求，例如：
用 jianying-editor 技能，把這個資料夾的素材剪成一支 1 分鐘的精華影片，
配輕快音樂、加字幕，草稿命名「測試1」

完成後打開剪映就會看到新草稿，檢查、微調後再匯出。

電商怎麼用

  • 把一批商品實拍片段，一句話剪成 15～60 秒的開箱／新品短影音草稿。
  • 寫好文案，讓它自動配音＋逐句對字幕，量產 Reels、抖音、蝦皮短影音。
  • 同一批素材改說「換成 30 秒版本、改成直式」，快速做出多個版本測廣告。

已知限制

  • 只生成剪映草稿，最後要在剪映裡檢查和匯出。
  • 自動匯出靠 UI 自動化：剪映 5.9 以下最穩；新版剪映可能失敗，失敗就手動按匯出。執行自動匯出時不要動鍵盤滑鼠。
  • 剪映內建的 AI 功能（智慧摳圖、美顏、語音辨識字幕、一鍵成片）叫不動。
  • 相機 RAW 檔（例如 .RAF、.CR3、.NEF）剪映讀不了，要先轉成 JPG。
  • 第一次建議只拿 10 到 20 個素材測試。

The workflow at a glance

  • ① Check JianYing
  • ② Install Python / Git / FFmpeg
  • ③ Install the skill
  • ④ Verify drafts are found
  • ⑤ One sentence → draft
  • ⑥ Review & export in JianYing

The skill builds the timeline for you; previewing, rendering and exporting still happen inside JianYing.

Before you start

  1. Install JianYing Pro (剪映专业版), the mainland-China desktop app from jianying.com. CapCut (international) and the mobile app are not supported.
  2. JianYing must contain at least one draft. If it has none, open JianYing and create an empty one.
  3. Use the Claude desktop app with a local session (a cloud session can't reach JianYing on your PC).

1Check for Python, Git and FFmpeg

Open PowerShell and check:

python --version; git --version

If anything is missing, install it:

winget install Python.Python.3.12 Git.Git Gyan.FFmpeg

Afterwards, close and reopen PowerShell so the new PATH takes effect.

2Install the skill (manual, safer method)

⚠️ Do not use the README's irm ... | iex one-liner. It downloads a script from a short link and runs it immediately, so you can't see what it does. Use the manual steps below.

git clone https://github.com/luoluoluo22/jianying-editor-skill.git "$env:USERPROFILE\.claude\skills\jianying-editor"
cd "$env:USERPROFILE\.claude\skills\jianying-editor"
git checkout 32c56928ded4f9e2c2b80e099dc7abb793d2c30b
(Get-Content requirements.txt) -replace '==.*','' | Set-Content req-loose.txt
python -m pip install -r req-loose.txt
python -m playwright install chromium

What each line does

  • git clone: downloads the skill into Claude's skills folder, ~\.claude\skills\jianying-editor, so Claude can find it.
  • git checkout 32c5692…: pins the reviewed v1.7 commit, so later upstream changes don't run unreviewed.
  • req-loose.txt: strips version pins from requirements so newer Pythons (e.g. 3.14) can still find compatible packages.
  • pip install: installs the Python packages the skill needs.
  • playwright install chromium: installs the browser used to record web animations as video.

3Verify it can see JianYing

From the same folder, run:

python scripts\draft_inspector.py list --limit 5

✅ If it lists your JianYing draft names, the install worked.

If it errors, paste the full message to Claude and ask it to troubleshoot. Common causes: no drafts in JianYing yet, CapCut installed instead of JianYing Pro, or PowerShell not reopened after installing.

4Using it

  1. In the Claude desktop app, start a local session (not cloud).
  2. Pick the folder that holds your footage as the working folder.
  3. Describe what you want, for example:
Use the jianying-editor skill to cut the footage in this folder into a
1-minute highlight video with upbeat music and captions. Name the draft "Test1".

Open JianYing afterwards and the new draft is there. Review, tweak, then export.

For sellers

  • Turn a batch of product clips into a 15–60s unboxing or launch video draft with one sentence.
  • Write the script and let it add voice-over plus line-by-line captions to mass-produce Reels and short-form ads.
  • Ask for "a 30-second vertical version" of the same footage to spin up ad variants for testing.

Known limitations

  • It only creates JianYing drafts; you still review and export in JianYing.
  • Auto-export relies on UI automation: most reliable on JianYing 5.9 or earlier; newer versions may fail, so just click Export yourself. Don't touch the keyboard or mouse while auto-export runs.
  • JianYing's built-in AI features (smart cutout, beauty filters, speech-to-caption, one-click video) can't be triggered.
  • Camera RAW files (e.g. .RAF, .CR3, .NEF) can't be read by JianYing; convert to JPG first.
  • For your first run, test with only 10 to 20 clips.
